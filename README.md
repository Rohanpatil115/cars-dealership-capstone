# Cars Dealership – Full-Stack Web Application

## Repository Name
`cars-dealership-capstone`

## Project Name
**Cars Dealership – Full-Stack Development Capstone Project**

## Project Description
This project is a full-stack web application developed for a national car dealership retailer in the United States.

The application allows users to:
- View dealership branches across different locations.
- Search and filter dealerships by state.
- Register and log in to their accounts.
- View dealership details.
- Read and submit dealership reviews.
- Analyze customer reviews using sentiment analysis.

## Technologies
- Frontend: React, HTML, CSS, JavaScript
- Backend: Django, Python
- Database: SQLite / MongoDB
- API: REST API
- DevOps: Docker, Kubernetes, GitHub Actions
- Deployment: IBM Cloud Code Engine

## Project Objective
The objective is to develop a responsive and user-friendly dealership platform that connects customers with dealership locations and enables them to share their experiences through reviews.
